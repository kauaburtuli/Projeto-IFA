Relógio Visual por Cores com LED RGB

O Relógio Visual por Cores utiliza um LED RGB para representar os períodos do dia por meio de cores, facilitando a identificação da manhã, tarde e noite. Essa abordagem torna a informação mais intuitiva e acessível, especialmente para pessoas que possuem dificuldade em interpretar relógios convencionais.

O que é?

O Relógio Visual por Cores é um protótipo desenvolvido utilizando a plataforma Arduino Uno R3, um LED RGB, resistores, jumpers e uma protoboard, com o objetivo de representar os períodos do dia por meio de diferentes cores. Em vez de utilizar números, ponteiros ou displays para informar o horário, o sistema faz uso de estímulos visuais simples, associando azul à manhã, verde à tarde e vermelho à noite. Dessa forma, o usuário consegue identificar rapidamente em qual período do dia se encontra apenas observando a cor emitida pelo LED.

Como o Arduino Uno R3 não possui um Relógio de Tempo Real (RTC) integrado, a passagem do tempo é simulada utilizando a função millis(). Essa função registra o tempo, em milissegundos, desde que a placa foi ligada. Com base nesse contador, o programa divide o funcionamento em ciclos previamente definidos, alternando automaticamente entre as cores que representam manhã, tarde e noite. Ao final do ciclo, o sistema reinicia a contagem e repete continuamente a sequência, simulando a passagem dos períodos do dia de forma simples e eficiente.

Além de demonstrar conceitos fundamentais de programação, lógica computacional e eletrônica embarcada, o projeto possui um forte caráter educacional e inclusivo. Durante seu desenvolvimento, os estudantes aprendem sobre variáveis, estruturas condicionais, controle de tempo com millis(), manipulação de portas digitais e funcionamento de LEDs RGB, compreendendo como componentes eletrônicos podem ser utilizados para resolver problemas do cotidiano.

O principal diferencial do projeto está em sua relação com a acessibilidade. Muitas pessoas apresentam dificuldades para interpretar relógios analógicos ou mesmo relógios digitais, seja por limitações cognitivas, dificuldades de aprendizagem, idade ou outros fatores. Ao substituir a leitura de horas por uma linguagem baseada em cores, o sistema torna a informação muito mais intuitiva e de rápida compreensão, reduzindo a necessidade de interpretar números ou ponteiros.

Essa solução pode beneficiar, por exemplo, crianças em fase de alfabetização, que ainda estão aprendendo a reconhecer as horas; idosos, que podem apresentar dificuldades visuais ou cognitivas; e pessoas com deficiência intelectual ou transtornos do desenvolvimento, que frequentemente respondem melhor a estímulos visuais simples e repetitivos. A associação entre uma cor e um período do dia facilita a criação de uma rotina, permitindo que o usuário compreenda quando é momento de estudar, trabalhar, descansar ou realizar outras atividades diárias.

Outro aspecto importante é que o projeto demonstra como a tecnologia pode ser utilizada para desenvolver recursos de Tecnologia Assistiva, ou seja, soluções que promovem maior autonomia, inclusão e qualidade de vida para diferentes públicos. Embora seja um protótipo simples e de baixo custo, ele evidencia que pequenos recursos tecnológicos podem tornar informações do cotidiano mais acessíveis, contribuindo para a participação de todos em atividades educacionais e sociais.

Além disso, o sistema pode ser facilmente expandido em versões futuras, incorporando novos recursos como um módulo RTC para informar o horário real, um display LCD ou OLED para exibir informações complementares, um buzzer para emitir sinais sonoros, motores vibratórios para fornecer retorno tátil ou até integração com sensores e dispositivos inteligentes. Essas melhorias permitiriam atender diferentes perfis de usuários, ampliando ainda mais a acessibilidade do projeto.

Portanto, o Relógio Visual por Cores vai além de um simples circuito com LED RGB. Ele representa uma aplicação prática dos conhecimentos adquiridos em programação e eletrônica, demonstrando como a tecnologia pode ser utilizada para criar soluções inclusivas, intuitivas e de baixo custo. Ao transformar a informação do tempo em um código de cores de fácil interpretação, o projeto incentiva o desenvolvimento de sistemas mais acessíveis, reforçando a importância da inovação tecnológica voltada para a inclusão e para a melhoria da qualidade de vida das pessoas.

Relógio Visual por Cores com LED RGB



                // ==========================================================
                // RELÓGIO VISUAL POR CORES
                // Arduino Uno R3 + LED RGB
                // ==========================================================

                // Define o pino conectado à cor vermelha do LED RGB
                const int LED_VERMELHO = 9;

                // Define o pino conectado à cor verde do LED RGB
                const int LED_VERDE = 10;

                // Define o pino conectado à cor azul do LED RGB
                const int LED_AZUL = 11;


                // ----------------------------------------------------------
                // CONFIGURAÇÃO DOS TEMPOS
                // ----------------------------------------------------------

                // Define quanto tempo cada período irá durar.
                // O valor é dado em milissegundos.

                // 10 segundos = 10000 milissegundos
                const unsigned long TEMPO_MANHA = 10000;

                // 10 segundos = 10000 milissegundos
                const unsigned long TEMPO_TARDE = 10000;

                // 10 segundos = 10000 milissegundos
                const unsigned long TEMPO_NOITE = 10000;


                // Soma todos os períodos para formar um ciclo completo
                const unsigned long TEMPO_CICLO =
                TEMPO_MANHA + TEMPO_TARDE + TEMPO_NOITE;


                // ----------------------------------------------------------
                // VARIÁVEL PARA CONTROLAR O TEMPO
                // ----------------------------------------------------------

                // Guarda o momento em que o ciclo começou
                unsigned long inicioCiclo = 0;


                // ==========================================================
                // FUNÇÃO SETUP
                // Executada apenas uma vez quando o Arduino é ligado
                // ==========================================================

                void setup() {

                // Define o pino vermelho como saída
                pinMode(LED_VERMELHO, OUTPUT);

                // Define o pino verde como saída
                pinMode(LED_VERDE, OUTPUT);

                // Define o pino azul como saída
                pinMode(LED_AZUL, OUTPUT);

                // Garante que o LED comece apagado
                apagarLED();

                // Guarda o tempo inicial do Arduino
                inicioCiclo = millis();
                }


                // ==========================================================
                // FUNÇÃO LOOP
                // Executada continuamente pelo Arduino
                // ==========================================================

                void loop() {

                // Obtém o tempo atual desde que o Arduino foi ligado
                unsigned long tempoAtual = millis();

                // Calcula quanto tempo passou desde o início do ciclo
                unsigned long tempoDecorrido =
                    tempoAtual - inicioCiclo;


                // --------------------------------------------------------
                // VERIFICA SE ESTAMOS NO PERÍODO DA MANHÃ
                // --------------------------------------------------------

                if (tempoDecorrido < TEMPO_MANHA) {

                    // Acende o LED na cor azul
                    mostrarAzul();
                }


                // --------------------------------------------------------
                // VERIFICA SE ESTAMOS NO PERÍODO DA TARDE
                // --------------------------------------------------------

                else if (tempoDecorrido <
                        TEMPO_MANHA + TEMPO_TARDE) {

                    // Acende o LED na cor verde
                    mostrarVerde();
                }


                // --------------------------------------------------------
                // CASO CONTRÁRIO, É O PERÍODO DA NOITE
                // --------------------------------------------------------

                else {

                    // Acende o LED na cor vermelha
                    mostrarVermelho();
                }


                // --------------------------------------------------------
                // VERIFICA SE O CICLO TERMINOU
                // --------------------------------------------------------

                if (tempoDecorrido >= TEMPO_CICLO) {

                    // Reinicia o contador do ciclo
                    inicioCiclo = tempoAtual;
                }
                }


                // ==========================================================
                // FUNÇÃO PARA MOSTRAR A COR AZUL
                // Representa a MANHÃ
                // ==========================================================

                void mostrarAzul() {

                // Vermelho desligado
                digitalWrite(LED_VERMELHO, LOW);

                // Verde desligado
                digitalWrite(LED_VERDE, LOW);

                // Azul ligado
                digitalWrite(LED_AZUL, HIGH);
                }


                // ==========================================================
                // FUNÇÃO PARA MOSTRAR A COR VERDE
                // Representa a TARDE
                // ==========================================================

                void mostrarVerde() {

                // Vermelho desligado
                digitalWrite(LED_VERMELHO, LOW);

                // Verde ligado
                digitalWrite(LED_VERDE, HIGH);

                // Azul desligado
                digitalWrite(LED_AZUL, LOW);
                }


                // ==========================================================
                // FUNÇÃO PARA MOSTRAR A COR VERMELHA
                // Representa a NOITE
                // ==========================================================

                void mostrarVermelho() {

                // Vermelho ligado
                digitalWrite(LED_VERMELHO, HIGH);

                // Verde desligado
                digitalWrite(LED_VERDE, LOW);

                // Azul desligado
                digitalWrite(LED_AZUL, LOW);
                }


                // ==========================================================
                // FUNÇÃO PARA APAGAR O LED
                // ==========================================================

                void apagarLED() {

                // Desliga o vermelho
                digitalWrite(LED_VERMELHO, LOW);

                // Desliga o verde
                digitalWrite(LED_VERDE, LOW);

                // Desliga o azul
                digitalWrite(LED_AZUL, LOW);
                }
