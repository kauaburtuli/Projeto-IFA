Arco Íris com LED RGB

Este projeto utiliza um Arduino UNO e um LED RGB para criar diferentes combinações de cores, por meio da variação de um potenciômetro. As cores são formadas pela mistura das luzes vermelha, verde e azul, permitindo produzir várias tonalidades.

O que é?

Este projeto foi desenvolvido utilizando a plataforma Arduino UNO com o objetivo de demonstrar o funcionamento de um LED RGB por meio da criação de um efeito visual de arco-íris, obtido pela combinação das cores vermelha (Red), verde (Green) e azul (Blue). O sistema realiza a transição automática entre diversas tonalidades, produzindo um efeito contínuo e suave que evidencia o princípio da mistura aditiva de cores, amplamente utilizado em dispositivos eletrônicos, sistemas de iluminação e equipamentos digitais.

O LED RGB é formado por três diodos emissores de luz independentes, um para cada cor primária do sistema RGB. Ao controlar individualmente a intensidade luminosa de cada um desses canais, é possível gerar uma grande variedade de cores e efeitos visuais. Neste projeto, a programação foi desenvolvida para realizar a variação gradual da intensidade de cada canal, permitindo que as cores se misturem de forma harmoniosa e criem o conhecido efeito de arco-íris.

Para controlar a intensidade luminosa de cada cor, o Arduino UNO utiliza a técnica de Modulação por Largura de Pulso (PWM – Pulse Width Modulation). Essa técnica permite variar o brilho do LED alterando o tempo em que cada canal permanece ligado durante um ciclo, sem modificar a tensão de alimentação. Dessa forma, as transições entre as cores ocorrem de maneira suave, tornando o efeito visual mais agradável e demonstrando uma das principais aplicações das saídas PWM presentes nos microcontroladores.

A programação foi desenvolvida na linguagem C/C++, utilizando estruturas de repetição, variáveis e funções responsáveis por aumentar e diminuir gradualmente a intensidade das cores vermelha, verde e azul. Durante a execução do programa, enquanto uma cor reduz sua intensidade, outra aumenta progressivamente, formando uma sequência contínua de cores que se repete indefinidamente. Esse processo evidencia conceitos importantes de programação embarcada, como controle de tempo, manipulação de variáveis e utilização de portas de saída PWM.

Além de seu caráter didático, o projeto possui aplicações práticas em áreas como automação residencial, robótica, decoração, iluminação inteligente, painéis luminosos, efeitos visuais, sistemas de entretenimento e dispositivos eletrônicos que utilizam iluminação dinâmica para fornecer informações ao usuário ou melhorar a experiência visual.

Relação com a acessibilidade

Embora o objetivo principal do projeto seja demonstrar o controle de um LED RGB, ele também apresenta uma importante relação com a acessibilidade. Sistemas baseados em iluminação colorida podem ser utilizados para complementar ou substituir alertas sonoros, auxiliando principalmente pessoas com deficiência auditiva. Diferentes cores ou padrões de iluminação podem indicar notificações, mudanças de estado de um equipamento, alarmes ou outras informações importantes, tornando a comunicação mais visual e acessível.

O efeito de transição entre cores também pode ser aplicado em dispositivos que utilizam feedback visual, permitindo que usuários identifiquem diferentes condições de funcionamento sem depender exclusivamente de sons ou mensagens escritas. Dessa forma, este projeto demonstra como uma tecnologia simples e de baixo custo pode servir como base para o desenvolvimento de soluções mais inclusivas, contribuindo para a criação de sistemas eletrônicos que atendam às necessidades de um público mais amplo e promovam maior acessibilidade.

Códigos Fonte

Efeito Fade-In


                /* Define a porta PWM 11 como pino do LED.             */
                int pinoLed = 11;
                int incremento = 1;
                int brilho = 0;

                void setup() {

                 pinMode(pinoLed, OUTPUT);

                }

                void loop() {

                for (brilho; brilho <= 256; brilho += incremento) {

                 analogWrite(pinoLed, brilho);

                delay(100);

                 }

                }

Efeito Fade-Out



                int pinoLed = 11;
                int decremento = 5;
                int brilho = 255;

                void setup() {

                pinMode(pinoLed, OUTPUT);

                }

                void loop() {

                for (brilho; brilho >= -1; brilho -= decremento) {

                    analogWrite(pinoLed, brilho);

                    delay(50);

                }

                }

Efeito Fade-In e Fade-Out


                // LED ligado ao pino 11
                const int led = 11;

                int brilho = 0;
                int incremento = 1;

                void setup() {

                pinMode(led, OUTPUT);

                }

                void loop() {

                analogWrite(led, brilho);

                brilho += incremento;

                if (brilho <= 0 || brilho >= 255) {

                    incremento = -incremento;

                }

                delay(30);

                }
